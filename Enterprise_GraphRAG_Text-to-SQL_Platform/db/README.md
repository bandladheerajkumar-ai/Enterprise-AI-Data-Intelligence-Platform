# Employee Management System PostgreSQL Deliverables

Run the complete script with:

```bash
psql -d your_database -f employee_management_system.sql
```

Included:

- 20 relational tables with primary keys, foreign keys, constraints, and indexes
- Seed data for the requested volumes
- 5 views
- 5 stored procedures
- 5 triggers
- 25 SQL practice queries at the end of the SQL file
- Mermaid ER diagram in `employee_management_erd.md`

Requested sample data volumes:

- 200 employees
- 10 departments
- 20 teams
- 10 locations
- 5 offices
- 50 projects
- 25 clients
- 500 employee project assignments
- 400 employee skill assignments
- 5000 attendance records
- 500 leave requests
- 200 payroll records
- 300 performance reviews
- 300 employee training records
- 200 employee asset assignments
